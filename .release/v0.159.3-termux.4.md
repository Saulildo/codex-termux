# codex-termux 0.159.3-termux.4

Upstream: `rust-v0.159.3`.

Fixes Android daemon process tracking by consistently reading process state and
boot-relative start time from `/proc/<pid>/stat`. Stale records whose PID now
belongs to an inaccessible Android app no longer block daemon startup.
Includes the npm-backed startup and private socket fixes from `.2` and `.3`.
